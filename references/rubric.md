# Scoring rubric (8 dimensions, 0-10)

Score each site per dimension. Default weights are equal; adjust with research findings and state the weights in the report. Mark a score "(inferred)" when the site was read as text and not seen visually. Use half points sparingly.

| # | Dimension | 3 looks like | 6 looks like | 9 looks like |
|---|---|---|---|---|
| 1 | Visual design | Template look, one typeface, repeated layouts, stock or reused photos, low contrast | Clean and consistent, decent photography, some hierarchy | Distinct identity, strong type pairing, varied editorial layouts, purposeful motion |
| 2 | Listing (directory, category, rooms…) | Text-only items, few filters, slow paging | Images or logos, category filters, A–Z or sort | Rich cards with status, counts, multi-filters in the URL, map/list views |
| 3 | Detail page | Name and one fact, empty fields | Hours, location, contact, description | Everything a visitor needs plus offers, related items, deep link to map/booking |
| 4 | Map / key feature (wayfinding, booking engine, calculator) | Missing or PDF | Separate interactive page | Embedded, deep-linked from details, extra tools (find my car, routes) |
| 5 | Search | Only inside one section | Header search with results page | Predictive, grouped, both languages, typo/transliteration tolerant |
| 6 | Multi-language | One language, or broken second language | Mirrored layout with some errors | Native-quality copy, proper RTL, matched typefaces, isolated mixed text |
| 7 | Tech and SEO | Duplicate titles, no meta, missing alt, dead analytics, slow | Unique titles, some structured data, acceptable speed | Unique titles and descriptions, hreflang, JSON-LD, modern images, fast, accessible |
| 8 | Local fit | Ignores local calendar, payments, platforms, law | Some local touches (local phone, currency) | Seasonal hours and campaigns, local payments, local platforms, legal basics, tourist content |

## Overall design ranking
Rank sites by dimension 1 (visual design) into tiers: A (8+), B (7-7.5), C (6), D (5), E (≤4). Place the target site among them.

## Severity for issues
- **Critical:** visible errors that hurt trust or are cheap to fix (wrong names, conflicting facts, typos, broken language, empty pages), or site-wide SEO failures.
- **High:** missing core features competitors have (search, filters, offers), performance, analytics, accessibility failures.
- **Medium:** visual polish, layout variety, secondary content.
