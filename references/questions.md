# Question bank

Ask with AskUserQuestion: up to 4 questions per call, 2-4 options each (the tool adds "Other"). Put the recommended option first and add "(Recommended)". Always include a "Skip / you decide" style option where it makes sense. Pre-fill options from the quick look (Phase 0) and the user's extras.

## Call 1: what and why
1. **What kind of website is this?** (header: Site type). Options from detection, e.g. Shopping mall · Hotel · Bank · E-commerce store. Others: Corporate, Restaurant group, Real estate, Government, Education, Healthcare, Airline, Telecom.
2. **What's the goal?** (Goal) Full redesign · Quick fixes · Competitor comparison only · Client pitch.
3. **Who are the main visitors?** (Visitors, multiSelect) e.g. Local nationals · Expatriates · Regional tourists · Research it for me.
4. **Which countries does the site serve?** (Countries, multiSelect) pre-filled from country switchers, domains, phone codes, currency.

## Call 2: competitors and coverage
5. **Where should competitors come from?** (Markets, multiSelect) Same city/country · Region (e.g. Gulf) · Asia · US & Europe / Global best.
6. **Competitors** (Competitors) Suggest 15-20 for me (Recommended) · I'll name some · Mix of both.
7. **Languages to check** (Languages, multiSelect) detected versions, e.g. English · Arabic (RTL).
8. **Pages that matter most** (Pages, multiSelect) Homepage · Listing/directory · Detail page · Search, plus type-specific (Booking/checkout, Contact, Careers).

## Call 3: depth, outputs, permissions
9. **Research depth** (Research) Standard: audience + geography basics (Recommended) · Light: best practices only · Deep: full geography, laws, search demand, local competitors.
10. **Benchmark depth** (Benchmark) Standard ~15 sites (Recommended) · Quick ~8 · Deep 20+.
11. **Outputs** (Outputs, multiSelect) Research brief · Benchmark report · Component kit · CSS resource directory. (Build prompt: ask in a follow-up or include by default when "Full redesign".)
12. **Browsing permissions** (Permissions, multiSelect) Read public pages only · Allow crawling the target (limits asked later) · I'll log in where needed · Ask me each time.

Also ask (free text or follow-up): output folder path; any extras not yet shared.

## Presets by website type

| Type | Key pages | Typical research needs | Rubric emphasis |
|---|---|---|---|
| Shopping mall | Home, store directory, store page, map, events/offers, visit | Hours, store finder, parking, offers, events, dining, kids, tourists | Listing, detail, map/wayfinding, local fit |
| Hotel | Home, rooms, booking, offers, location | Booking flow, price clarity, photos, reviews, location | Booking, visual, trust |
| Bank | Home, products, rates, branches/ATMs, login entry | Trust, security cues, rates, calculators, accessibility | Search, clarity, accessibility, tech |
| E-commerce | Home, category, product, cart, checkout | Search, filters, product detail, delivery and returns, payments | Listing, detail, search, checkout |
| Restaurant group | Home, menus, locations, reservations, delivery | Menus, hours, booking, delivery apps | Detail, local fit, mobile |
| Corporate | Home, about, services, careers, contact | Positioning, credibility, case studies, careers | Visual, content, SEO |

Map rubric dimensions "Listing", "Detail" and "Map/key feature" to the type (e.g. for a hotel: rooms list, room page, booking engine).
