# Saudi Arabia: starter market profile

Starting point only. **Verify every line and cite a current source before using it.** Numbers (population, penetration, platform shares) are deliberately left out because they change; research them fresh.

| Area | Starter note |
|---|---|
| Currency | Saudi riyal (SAR) |
| Weekend | Friday-Saturday |
| Time zone | UTC+3 (Asia/Riyadh) |
| Phone code | +966 |
| Languages | Arabic (official); English common in cities and among expatriates |
| Payments | mada (national debit scheme); STC Pay and other wallets; Apple Pay; BNPL Tabby and Tamara |
| Data protection | Personal Data Protection Law (PDPL), overseen by SDAIA (check implementing regulations) |
| Key dates | Founding Day 22 February, National Day 23 September; Islamic holidays move each year. Ramadan and Eid follow the Hijri calendar and move about 11 days earlier each year. |
| Notes | Very high social media use (check current platform shares, Snapchat and TikTok are strong). Large domestic tourism and events calendar. |
