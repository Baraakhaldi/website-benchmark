# Bahrain: starter market profile

Starting point only. **Verify every line and cite a current source before using it.** Numbers (population, penetration, platform shares) are deliberately left out because they change; research them fresh.

| Area | Starter note |
|---|---|
| Currency | Bahraini dinar (BHD), 3 decimal places |
| Weekend | Friday-Saturday |
| Time zone | UTC+3 (Asia/Bahrain) |
| Phone code | +973 |
| Languages | Arabic (official); English widely used |
| Payments | BENEFIT (national network, BenefitPay wallet); Visa/Mastercard; Apple Pay |
| Data protection | Personal Data Protection Law, Law No. 30 of 2018 |
| Key dates | National Day 16-17 December; Islamic holidays move each year. Ramadan and Eid follow the Hijri calendar and move about 11 days earlier each year. |
| Notes | Many weekend visitors from Saudi Arabia via the King Fahd Causeway: consider SAR price notes and Saudi-focused content. |
