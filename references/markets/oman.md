# Oman: starter market profile

Starting point only. **Verify every line and cite a current source before using it.** Numbers (population, penetration, platform shares) are deliberately left out because they change; research them fresh.

| Area | Starter note |
|---|---|
| Currency | Omani rial (OMR), 3 decimal places |
| Weekend | Friday-Saturday |
| Time zone | UTC+4 (Asia/Muscat) |
| Phone code | +968 |
| Languages | Arabic (official); English common in business |
| Payments | OmanNet (national network); Visa/Mastercard |
| Data protection | Personal Data Protection Law, Royal Decree 6/2022 (check executive regulations) |
| Key dates | National Day in November (check the current date); Islamic holidays move each year. Ramadan and Eid follow the Hijri calendar and move about 11 days earlier each year. |
| Notes | Strong domestic and regional tourism in cooler months; Salalah khareef season in summer. |
