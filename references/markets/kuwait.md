# Kuwait: starter market profile

Starting point only. **Verify every line and cite a current source before using it.** Numbers (population, penetration, platform shares) are deliberately left out because they change; research them fresh.

| Area | Starter note |
|---|---|
| Currency | Kuwaiti dinar (KWD), 3 decimal places |
| Weekend | Friday-Saturday |
| Time zone | UTC+3 (Asia/Kuwait) |
| Phone code | +965 |
| Languages | Arabic (official); English widely used in retail and business |
| Payments | KNET (national debit network); Visa/Mastercard; Apple Pay; BNPL such as Tabby (check current providers) |
| Data protection | CITRA Data Privacy Protection Regulation (check the latest version and amendments) |
| Key dates | National Day 25 February, Liberation Day 26 February; Islamic holidays move each year. Ramadan and Eid follow the Hijri calendar and move about 11 days earlier each year. |
| Notes | Large expatriate population: English content is essential alongside Arabic. Hot summers push visits indoors and into the evening. |
